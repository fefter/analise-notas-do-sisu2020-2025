# Dashboard SISU — Análise das Notas de Corte (2020 - 2025)

## Sobre o Projeto

Este projeto consiste em um dashboard desenvolvido no Power BI para análise das notas de corte do SISU entre os anos de 2020 e 2025.

O objetivo principal é visualizar e comparar o comportamento das notas de corte ao longo dos anos, identificando tendências de crescimento, estabilidade e variações entre diferentes cursos.

Os cursos analisados foram:

- Direito
- Filosofia
- Fisioterapia
- Medicina
- Psicologia

---

# Objetivos do Dashboard

- Comparar médias das notas de corte entre cursos;
- Identificar crescimento ou redução das notas ao longo dos anos;
- Visualizar tendências históricas;
- Facilitar análises comparativas de forma interativa;
- Transformar dados brutos em informações visuais e interpretáveis.

---

# Funcionalidades

## Filtros Interativos

O dashboard permite filtrar informações por:

- Curso
- Ano

---

## Cards Dinâmicos

O painel apresenta indicadores automáticos como:

- Máxima de nota;
- Média geral das notas;
- Crescimento percentual.

---

## Histórico Temporal

Gráfico de linha mostrando a evolução das médias das notas de corte entre 2020 e 2025.

---

## Comparação Entre Cursos

Gráfico de barras permitindo comparar as médias dos cursos analisados.

---

## Crescimento Percentual

Visualização da variação percentual das notas ao longo dos anos.

---

# Indicadores Utilizados

## Média das Notas

```text
Soma das notas / Quantidade de registros
```

---

## Crescimento Percentual

```text
((Valor Atual - Valor Anterior) / Valor Anterior) * 100
```

---

## Nota Máxima

```text
Maior nota registrada entre os cursos e anos analisados
```

---

# Visualizações Utilizadas

# Principais Análises

## Medicina

O curso de Medicina apresentou as maiores médias e notas máximas durante praticamente todo o período analisado.

---

## Filosofia

Filosofia apresentou as menores médias entre os cursos analisados, além de maior oscilação em alguns períodos.

---

## Direito e Psicologia

Os cursos apresentaram comportamento relativamente estável, mantendo médias intermediárias ao longo dos anos.

---

## Tendências Gerais

A análise mostra que houve variações importantes nas notas de corte entre os anos, permitindo identificar períodos de crescimento e estabilidade.
